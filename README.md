## 便宜香港VPS 的价格差，主要差在这四件事

### 线路：国际线路和三网直连不是同一档

香港机房的带宽出口分两类。一类走国际骨干网（NTT、Cogent、RETN 这些），对接亚太和欧美很顺，但回中国大陆可能要绕日本或新加坡，晚高峰体验会掉。另一类是电信 CN2、移动 CMI、联通 CUG 这类大陆优化线路，延迟低、路由直，成本也高。

雨云把这个差别直接做成了不同区域。香港三区是三网直连（CN2+CMI+CUG），香港二区走移动 CMI 优化，香港四区是软银混合线路，香港五区则是纯国际大带宽线路。官方在更新日志里对五区的描述是"适合服务亚太等海外用户，国内连通性较差"——这句话基本就是选型说明书，如果你网站访客主要在国内，五区不是首选。

### 流量模式：限流量和不限流量别买错

便宜的香港 VPS 常见两套计费：一套给大带宽但限月流量，另一套不限流量但带宽压得很低。

以雨云香港二区的同一档 2 核 2G 为例，大带宽型给 50Mbps、月流量 100GB，不限流量型的上传带宽只有 10Mbps，两边价格一样。香港三区也是这个逻辑：不限流量款 2 核 2G 只有 5Mbps 上下行对等带宽。

选错的代价很直接。挂博客、跑面板、做接口服务，流量消耗不大，选不限流量型更省心；做视频站、下载站或图片多的电商站，需要的是突发带宽，限流量型反而更合适。还有一点值得知道：雨云的流量按月自动叠加，这个月没用完的会结转到下个月，不是月底清零。

### 带宽、IP 和防御：账单上的隐藏项

标价通常只含 1 个 IPv4。额外加 IP 是 5 元/个/月。要跑需要独立 IP 的服务、做多站分离，这笔钱得算进去。

防御是另一个变量。普通香港 IP 没有防御，需要 300G+ 级别的高防 IP 要另外付费，不同区域在 30 到 40 元/月这个区间。

硬盘方面，雨云的云服务器无论哪个套餐起步都是 30GB，可以弹性扩容，按 0.12 元/10GB/天计费，折算下来大约 3.6 元/10GB/月。当站长大附件多，扩容成本要提前估。
